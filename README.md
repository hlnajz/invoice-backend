# 🍰 SweetInvoice AI (Backend)

**The simplest way to create and send professional invoices.**

SweetInvoice is a smart, AI-powered invoicing platform designed for freelancers, small businesses, and entrepreneurs. It allows you to create professional invoices in seconds, manage clients efficiently, and export invoices as PDF — all from a clean and intuitive dashboard.

---

## 🚀 Overview

SweetInvoice streamlines billing workflows by combining automation, AI intelligence, and a modern user experience.

Whether you're a freelancer managing a few clients or a growing startup handling dozens of invoices, SweetInvoice helps you:

- Create invoices instantly
- Track payments
- Automate reminders
- Monitor financial performance
- Export professional PDFs

## ✨ Features

### 🤖 AI Invoice Generator
Paste receipts, emails, or plain text and let SweetInvoice automatically generate a structured, professional invoice.

### 📊 Smart Finance Dashboard
Monitor:
- Revenue
- Outstanding payments
- Client activity
- AI-powered financial insights

### 📧 Automated Payment Reminders
Send polite, professional reminder emails automatically for overdue invoices to improve cash flow.

### 🗂 Seamless Invoice Management
Organize, track, and manage all invoices in one place with clear payment status and easy access controls.
